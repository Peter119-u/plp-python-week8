Personal Mini-Toolkit
Project Description

This project is a Python-based personal mini-toolkit that provides several simple tools through a menu-driven program. The toolkit allows the user to choose different tools and return to the main menu after each tool is completed.

Tools

The toolkit will include:

A simple calculator
A to-do list
A number-guessing game

The program uses Python variables, input/output, conditionals, loops, lists, and f-strings.

How to Run
Make sure Python is installed on your computer.
Clone or download this repository.
Open a terminal in the project folder.
Run the program with:
python toolkit.py

Follow the menu instructions displayed by the program.

Reflection

This project helped me bring together the Python concepts I learned during the course. The hardest part was designing the menu so that it could keep running until the user chose to quit. I also had to think carefully about how the different tools would work together in one program. The bug that took the longest to fix was making sure the program handled invalid menu choices without crashing. Using lists for the to-do tool helped me understand how data can change while a program is running. I also learned how comments and clear output make code easier for another person to understand. With one more week, I would add more useful tools and improve the design of the existing ones.
